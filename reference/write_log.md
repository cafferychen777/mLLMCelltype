# Write Log Utility Function

This function writes log messages to a file with timestamps and also
prints them to the console.

## Usage

``` r
write_log(message, log_file = "llm_celltype.log")
```

## Arguments

- message:

  Character string containing the log message to write

- log_file:

  Character string specifying the log file name (default:
  "llm_celltype.log")

## Value

None, used for side effects
